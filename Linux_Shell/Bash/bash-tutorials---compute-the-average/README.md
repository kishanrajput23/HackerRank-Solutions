## [Compute the Average](https://www.hackerrank.com/challenges/bash-tutorials---compute-the-average/problem)

**Domain:** Linux Shell  
**Subdomain:** Bash  
**Difficulty:** Medium  

**Problem Description:**

<div class='challenge_problem_statement'><div class='msB challenge_problem_statement_body'><div class='hackdown-content'><p>Given  integers, compute their average, rounded to three decimal places.  </p>

<p><strong>Input Format</strong> <br>
The first line contains an integer, . <br>
Each of the following  lines contains a single integer.  </p>

<p><strong>Output Format</strong> <br>
Display the average of the  integers, rounded off to three decimal places.  </p>

<p><strong>Input Constraints</strong> <br>
 <br>
 ( refers to elements of the list of integers for which the average is to be computed)  </p>

<p><strong>Sample Input</strong></p>

<pre><code>4
1
2
9
8
</code></pre>

<p><strong>Sample Output</strong></p>

<pre><code>5.000
</code></pre>

<p><strong>Explanation</strong> <br>
The '4' in the first line indicates that there are four integers whose average is to be computed.</p>

<p>The average = (1 + 2 + 9 + 8)/4 = 20/4 = 5.000 (correct to three decimal places).</p>

<p>Please include the zeroes even if they are redundant (e.g. 0.000 instead of 0).</p></div></div></div>
